# Description

## E9patch Replay Backend

Implement a deterministic replay backend using e9patch software branch counting.
This enables replay without PMU hardware — works in VMs, containers, and CI.

## Architecture (see ai_docs/record_replay_architecture.md section 4)

### How it works:
1. Record preemption points with any backend (PMU or e9patch recording)
2. Replay uses the e9 trampoline's deterministic branch counter
3. For each target: compute delta = target.structop_rbc - accumulated_rbc
4. Set e9 counter to fire after delta branches
5. When counter expires, verify at correct instruction, yield token

### Key design:
- New struct: E9PatchReplayBackend implementing PreemptionBackend trait
- arm(): set e9 counter via arm_e9_counter(delta)
- yield handler: verify instruction, advance cursor, return new delta
- No PMU, no signals, no retry logic — fully deterministic

### Implementation steps:

T1: Create E9PatchReplayBackend struct in backend/e9patch.rs
- Implement PreemptionBackend trait
- build_target(): read from ReplayCursor, compute RbcTarget::Relative(delta)
- arm(): call e9 arm function with delta count
- read_count(): return current e9 counter value

T2: Implement e9 replay yield handler
- In csrc/e9_rbc_trampoline.c or a new replay trampoline
- When counter expires: call back into Rust
- Rust side: verify instruction bytes, validate ops_context
- Yield the token (same as current preemption yield)

T3: Wire up CLI
- Add --replay-backend e9patch option (or auto-detect from trace metadata)
- Integrate with replay_dispatch_with_retry (no retry needed for e9)

T4: Counter compatibility validation
- Verify e9 Jcc count matches PMU retired-branches for same code path
- If they differ, add a scaling factor or record which counter was used

T5: Integration test
- Record with PMU, replay with e9patch
- Record with e9patch, replay with e9patch
- Both should produce identical simulation results

### Dependencies:
- e9patch must be installed (make install-e9patch)
- Scheduler .so must be instrumented (make -C schedulers e9)
