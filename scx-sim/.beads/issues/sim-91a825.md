# Description

power.bpf.c::set_power_profile is a SEC(syscall) prog userspace invokes to change power mode. scxsim has no API to inject a syscall-prog call mid-run. Direct FFI call aborts: its body (do_set_power_profile->update_power_mode_time->scx_bpf_now) needs an installed sim context (SIM_ARC), present only during Simulator::run. So the one-line wrapper is uncoverable; its body do_set_power_profile IS covered via the autopilot path (do_autopilot). Work: API to invoke a SEC(syscall) prog within an active sim step. Found by tg cover-lavd-power-idle-gaps.
