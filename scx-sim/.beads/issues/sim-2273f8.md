# Description

Three related replay issues found by investigation:

1. No fast-path for structop_rbc < REPLAY_MARGIN(200): PMU period=1, guaranteed overshoot on all 3 retries, wastes time before falling back to bp-only.

2. Latent crash: arm_replay_next_target checks timer_fd >= 0 instead of no_pmu_signal, so bp-only mode arms PMU timer for subsequent targets. SIGSTKFLT has no handler → process killed.

3. No per-target PMU skip for small deltas on subsequent targets.

Fix plan:
A. build_target: if structop_rbc < REPLAY_MARGIN, emit Relative(0)
B. arm_replay_next_target: check no_pmu_signal flag
C. arm_replay_next_target: if delta < REPLAY_MARGIN, fall back to breakpoint
