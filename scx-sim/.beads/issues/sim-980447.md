# Description

stress.py --determinism finds reproducible stalls with the tickless scheduler under cooperative interleaving mode, particularly with dsq_contention workload on 2-8 CPUs. Example: tickless/dsq_contention/c4/s2649358005/cooperative. The stall is ErrorStall, meaning a runnable task is not scheduled within the watchdog timeout.
