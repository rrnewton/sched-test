# Description

scxsim scenario API has only Run/Sleep/Wake phases + static allowed_cpus; TaskDef::initial_cpu() is kernel-faithful (first CPU always in cpumask). idle.bpf.c::pick_random_cpu (+ sole callee cpumask_any_distribute) is reached only when find_sticky_cpu_and_cpdom returns sticky_cpdom<0, needing prev_cpu NOT runnable (affinity excludes it). With static affinity + faithful placement, prev_cpu is never outside the allowed set -> unreachable (0%). The other route (cpu<0 fallback at idle.bpf.c:926) is source-annotated 'impossible'. Work: add a runtime affinity-narrowing event (Phase::SetAffinity / migrate_disable). Found by tg cover-lavd-power-idle-gaps.
