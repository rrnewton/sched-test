# Recipes

Task-shaped how-to pages. Each recipe answers one question:
"I want to do X. What is the shortest path?"

- [Reproducing a Stall Bug](./recipes/repro-stall.md) — using
  Bug-1 canonical as the worked example.
- [Comparing Two Schedulers](./recipes/compare-schedulers.md) — same
  workload, two `--scheduler` values, side-by-side traces.
- [Verifying Determinism](./recipes/verify-determinism.md) — proving
  a reproducer is byte-stable across runs.
- [Debugging with LLDB](./recipes/lldb.md) — `--wait-debugger`,
  attach commands, and the `bug1_diagnose` helper.
